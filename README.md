# SpatialForge — 3D Presentation Studio

**SpatialForge** is an experimental, browser-based spatial presentation editor built with Three.js. It combines imported GLB models, component selection, source-derived scenes, and an opt-in gesture-navigation prototype.

> **Project status:** Public preview / experimental alpha. This project is not independently certified as production-ready. Do not rely on it for critical live presentations without testing on your own device.

## What you can do

- Import self-contained **GLB** models (up to 25 MB), inspect mesh names and select components in 3D.
- Rotate and zoom 3D scenes, highlight selected meshes, and show screen-space labels connected to model components.
- Import text, PDF, PPTX, DOCX, CSV, and spreadsheets to extract source content; extraction quality varies by format.
- Create and edit slides and source-derived 3D chart or concept scenes.
- Use a separate presenter view with keyboard and pointer controls.
- Optionally enable webcam-based hand tracking for hold-pinch slide advancement.
- Save projects locally and export/import **portable ZIP bundles** containing a GLB model, with SHA-256 integrity checking.

## Quick start

Requires a modern browser with WebGL and internet access to third-party CDN dependencies.

```bash
python3 -m http.server 4173
```

Open **http://localhost:4173**. Import a GLB with **Import genuine 3D model**, or paste source content and choose **Generate scenes**. Choose **Present** to open the presenter view.

## Privacy and security

The editor stores project metadata in localStorage and imported GLB bytes in browser IndexedDB when available. Portable ZIP bundles contain your presentation data and model: review them before sharing. Webcam access is opt-in. Application code processes hand landmarks in the browser; external CDN libraries and model files are fetched over the network. **Do not import sensitive or confidential documents into an unreviewed public build.**

## Known limitations

- The app does **not** synthesize scientifically accurate physical models from arbitrary text.
- Model mesh names and annotations are imported metadata, **not independently verified facts**.
- A JSON project export references a model by hash but does not embed its bytes; use the portable ZIP bundle to transfer the model.
- Gesture recognition currently supports **hold-pinch to advance** only; grab, spread, fist, and other gestures are not yet implemented. Model annotation occlusion, advanced cinematography, accessibility, device compatibility, and full production reliability require further validation.
- This repository has not undergone a complete third-party security or dependency audit.
